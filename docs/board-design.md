# 为什么是这 12 人？——SOYA 董事会的选人逻辑

> 这不是一份"名人名单"，而是一套**思维工具库**。选人的标准不是"谁有名"，而是"谁的思想能真正帮到你"。

## 一、入选四问：每个人都要通过这 4 关

任何一个进入你私人董事会的人，必须同时满足：

| # | 问题 | 含义 | 反例 |
|---|------|------|------|
| 1 | **思想经得起时间检验吗？** | 至少被验证过数十年甚至上千年，不是流量红人 | 今天的"网红导师" |
| 2 | **覆盖一个无可替代的维度吗？** | 12 人各管一个关键人生维度，没有两个人在干同一件事 | 两个"都是讲效率的" |
| 3 | **思想能"编译"成可执行原则吗？** | 不只是提供洞见，还能给出"下次遇到 X 就做 Y"的算法 | 只给金句不给方法 |
| 4 | **跟其他人互补吗？** | 能跟别的成员"互怼"，分歧才有价值 | 全员都是乐观派 |

> 💡 第 4 条最重要：**董事会里必须有反对派**。马斯克说"干！"的时候，芒格会说"反过来想——最坏的结果你能承受吗？"。共识给你信心，分歧让你看清盲点。这就是董事会的价值所在。

## 二、12 人覆盖 6 大维度

一个成年人的生活问题，逃不出这 6 个维度。每个维度配 2 人（或 3 人），互为镜像：

```
┌─────────────────────────────────────────────────────────┐
│  怎么想  →  决策与理性     芒格（逆向） · 俞军（数据）    │
│  怎么做  →  执行与创新     马斯克（第一性原理）· 达·芬奇  │
│  怎么扛  →  心性与情绪     曾国藩 · 苏轼 · 杨绛           │
│  怎么走  →  方向与长期     凯文·凯利（趋势望远镜）        │
│  怎么活  →  自由与独立     波伏娃（存在主义）             │
│  怎么说  →  沟通与关系     沃斯（谈判）· 德鲁克（组织）   │
└─────────────────────────────────────────────────────────┘
```

**为什么每维 2 人？** 同一维度也需要"理性派"和"心性派"的张力：
- 决策时：芒格问"风险是什么"，俞军问"数据支持吗"——一个防冲动，一个防拍脑袋
- 沟通时：沃斯教你怎么"谈下来"，德鲁克教你怎么"被看见"——一个攻，一个守

## 三、12 人入选理由（逐个说明）

### 🧠 决策与理性

**查理·芒格（1924-2023）——"反着想"的理性标杆**
- **为什么选他**：伯克希尔·哈撒韦的副董事长，巴菲特之外最被低估的智者。他的多元思维模型 + 逆向思维，是决策质量的"刹车片"。
- **他解决什么**：冲动决策、盲目乐观、只考虑成功不考虑失败。
- **独有贡献**："反过来想，总是反过来想"——给所有重大决策一个强制检查步骤："如果我不想搞砸这件事，最该避开的是什么？"
- **一句话标签**：冲动决策的刹车片。

**俞军——"用户价值"的方法论者**
- **为什么选他**：中国产品经理方法论的奠基人（百度前产品副总裁），把产品决策从"感觉"变成"公式"。
- **他解决什么**：拍脑袋决策、看不清"用户到底要什么"。
- **独有贡献**：可计算的决策公式——"用户价值 = 新体验 − 旧体验 − 替换成本"。这套"用公式和实证代替直觉"的思维，能迁移到一切取舍场景。
- **一句话标签**：拍脑袋的对冲器。

### ⚡ 执行与创新

**埃隆·马斯克（1971-）——"第一性原理"的执行狂**
- **为什么选他**：用 SpaceX 和 Tesla 两次证明"别人觉得不可能的事，可以拆成物理事实"。代表极端执行力。
- **他解决什么**：目标恐惧、从众思维、"大家都这么做"的绑架。
- **独有贡献**：第一性原理——回到事物的本质重新计算，不被"行业惯例"和"历史经验"带偏。
- **一句话标签**：把"不可能"拆成"可执行"。

**达·芬奇（1452-1519）——"好奇心"的跨界天才**
- **为什么选他**：人类历史上罕见的艺术+科学+工程三栖天才。代表创造力与跨界思维。
- **他解决什么**：思维僵化、路径依赖、创意枯竭。
- **独有贡献**：跨界迁移——把绘画的观察方法用到工程，把解剖学用到雕塑。当你的问题卡住时，他的思维是"换个学科看这个问题"。
- **一句话标签**：思维僵化的解药。

### 🛡️ 心性与情绪

**曾国藩（1811-1872）——"修身"的实操派**
- **为什么选他**：中国修身哲学里最"可操作"的一位。别人谈境界，他给方法——写日记、立日课、结硬寨打呆仗。
- **他解决什么**：道理都懂就是做不到、逆境中定力不足、想太多做太少。
- **独有贡献**：把"自律"从口号变成每日可执行的流程。SOYA 晨会的"事实简报 → 行动清单"结构，思想源头就是他。
- **一句话标签**：逆境的耐磨层。

**苏轼（1037-1101）——"豁达"的情绪大师**
- **为什么选他**：一生被贬三次（黄州、惠州、儋州），却在任何环境里都能写出"也无风雨也无晴"。中国文人情绪管理的天花板。
- **他解决什么**：内耗、焦虑、把一次失败当成终局。
- **独有贡献**：把"逆境"重新定义为"体验"。他证明：处境不能改变时，对处境的态度可以改变。
- **一句话标签**：内耗的粉碎机。

**杨绛（1911-2016）——"内心宁静"的精神导师**
- **为什么选她**：经历了一个世纪最深的动荡，却始终相信"世界是自己的"。钱钟书夫人，作家、翻译家。
- **她解决什么**：被外界评价绑架、精神内耗、注意力涣散。
- **独有贡献**：注意力管理——"你的问题主要在于读书不多而想得太多"。把注意力从"别人怎么看我"拉回"我自己要什么"。
- **一句话标签**：精神的定海神针。

### 🔭 方向与长期

**凯文·凯利（1952-）——"长期主义"的望远镜**
- **为什么选他**：《失控》《必然》作者，《连线》杂志创始主编，用 20 年尺度观察技术与社会。
- **他解决什么**：短期焦虑、职业方向迷茫、看不懂技术趋势。
- **独有贡献**：趋势判断——"未来已来，只是分布不均"、"20 年后最好的产品今天还没发明"。当你焦虑于眼前时，他负责把时间线拉长。
- **一句话标签**：焦虑的解药是拉长时间线。

### 🕊️ 自由与独立

**波伏娃（1908-1986）——"自由选择"的存在主义者**
- **为什么选她**：《第二性》作者，存在主义哲学家。她的核心命题是"存在先于本质"——你不是被定义出来的，你是自己创造出来的。
- **她解决什么**：不敢为自己而活、被性别/年龄/身份标签定义、害怕承担选择的后果。
- **独有贡献**：自由与责任的一体两面——选择是自由的，但每个选择都要自己负责。她逼你回答："如果没有任何人在看，你会选什么？"
- **一句话标签**：独立人生的宣言。

### 🎯 产品与策略（工作场景）

**张小龙（1969-）——"克制"的产品哲学家**
- **为什么选他**：微信之父，Foxmail 作者。示范了"少即是多"的产品哲学。
- **他解决什么**：什么都想要、需求泛滥、不会取舍。
- **独有贡献**：克制之道——判断什么是"不该做的"。他的问题清单："用户真的需要吗？这是自然的产品形态吗？"
- **一句话标签**：需求的过滤器。

### 🏢 组织与职场

**彼得·德鲁克（1909-2005）——"有效性"的管理学之父**
- **为什么选他**：现代管理学奠基人（《卓有成效的管理者》作者）。他定义了"有效"：效率是把事情做对，效果是做对的事情。
- **他解决什么**：忙而无功、成果不被看见、不会向上管理。
- **独有贡献**：贡献思维 + 向上管理——先问"我能为组织贡献什么"，再让工作成果成为上级决策的有效输入。SOYA 晨会里"绩效沟通"类议题的第一咨询人。
- **一句话标签**：职场贡献的翻译官。

**克里斯·沃斯（1964-）——"战术共情"的谈判专家**
- **为什么选他**：前 FBI 国际人质谈判专家，《掌控谈话》作者。处理过 150+ 起人质事件，是最懂"高压对话"的人。
- **他解决什么**：一谈就崩、不敢谈资源、不会处理冲突。
- **独有贡献**：校准问题 + 战术共情——先准确说出对方的处境和感受（"听起来你的压力很大"），再用 How/What 问题把对抗变成共同解题。
- **一句话标签**：高压对话的灭火器。

## 四、为什么没有"当代红人"？

这是一个被问最多、也最值得诚实回答的问题：

1. **董事会不是名人堂，是思维工具库。** 入选标准是"思想被时间检验 + 可编译成原则"。当代红人的影响力大多未经时间检验，方法论往往还没沉淀成可复用的原则。
2. **成员必须是"常量"。** 你每次请教都希望得到可靠的回答。思想的稳定性，来自它被验证的时长——苏轼被验证了 900 年，曾国藩被验证了 150 年。
3. **这不代表名单不可更新。** 见下一篇《如何组建你自己的董事会》——10 年后你可以把当代真正经过检验的思想家请进来。

## 五、怎么读这份名单

- **先深后广**：从 12 人中选 2-3 个你最有共鸣的，读原著（书单见 `personal-board/README.md`），真正理解他们的思维方式。
- **理解而非背诵**：不要记住"马斯克会怎么说"，要理解"第一性原理怎么用"。
- **用起来才算数**：档案是起点不是终点，真正的理解来自实践。
