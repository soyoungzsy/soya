# 如何组建你自己的董事会？——选人、复用与定制指南

> 默认的 12 人董事会只是一个**起点模板**。它证明这套机制有效，但真正属于你的董事会，必须由你自己组建。

## 一、三步选人法：每次咨询怎么选 3-5 人

董事会成员一次不必全员出场。**每次 3-5 人**，按三步选：

### 第 1 步：定位议题（我的问题属于哪一维？）

| 你面临的问题 | 属于哪一维 |
|------------|-----------|
| 要不要换工作 / 要不要创业 / 要不要买房 | 决策与理性 |
| 目标太大不敢动 / 事情做不出来 | 执行与创新 |
| 焦虑、内耗、失眠、被批评了难受 | 心性与情绪 |
| 职业方向迷茫 / 看不懂趋势 | 方向与长期 |
| 不敢做自己 / 被身份标签困住 | 自由与独立 |
| 绩效沟通 / 谈薪资 / 向上管理 / 冲突 | 沟通与关系 |

### 第 2 步：匹配思维（这一维需要什么思维方式？）

- 决策类 → 需要"逆向防呆"（芒格）+"数据实证"（俞军）
- 执行类 → 需要"第一性原理"（马斯克）+"跨界破局"（达·芬奇）
- 情绪类 → 需要"耐烦"（曾国藩）+"豁达"（苏轼）+"宁静"（杨绛）
- 方向类 → 需要"长期视角"（凯文·凯利）
- 自由类 → 需要"存在主义"（波伏娃）
- 沟通类 → 需要"战术共情"（沃斯）+"贡献思维"（德鲁克）

### 第 3 步：查表选人（本维 2-3 人 + 相邻维 1-2 人）

**公式：核心阵容（2-3 人）+ 制衡阵容（1-2 人）= 3-5 人**

- 核心阵容负责"主攻"，制衡阵容负责"挑刺"——分歧恰恰是董事会价值所在。
- 例：换工作问题 → 核心：芒格、俞军（决策）+ 制衡：凯文·凯利（长期）、苏轼（心态）。

## 二、场景阵容速查表（抄作业专用）

| 场景 | 推荐阵容 | 理由 |
|------|---------|------|
| **绩效沟通 / 向上管理** | 德鲁克 + 沃斯 + 曾国藩 + 芒格 | 德鲁克定义贡献、沃斯教话术、曾国藩稳住心态、芒格防冲动 |

## 三、定制三部曲：把董事会变成"你的"

### ① 加人：请进你敬佩的人

选新人，用同一个**入选四问**把关：

1. 思想经得起时间检验吗？
2. 覆盖一个我缺的维度吗？（注意：不是"我喜欢"，是"我需要"）
3. 思想能编译成可执行原则吗？
4. 跟现有成员互补吗？

通过四问后，用**空白成员卡**（`templates/member-card.md`）建档，然后告诉你的 AI 助手："把我的董事会加上 X，档案在 member-card.md 里。"

### ② 换人：什么时候换、怎么换

| 情况 | 动作 |
|------|------|
| 某位成员的思想你已**完全内化**（不用"调用"也能想到） | 可以考虑让位给新成员 |
| 某位成员的建议**反复不合时宜**（换了场景还是这样） | 说明你对他的理解有偏差，先回去读原著 |
| 你的人生阶段变了（学生→职场→管理→创业） | 调整阵容权重，而非全部换掉 |
| 出现了真正经过检验的新思想 | 用入选四问评估后，小步增补 |

> ⚠️ **换人不是换头像**。如果你频繁换人、却从没深入了解过任何一位，问题不在名单，在"贴标签"式使用——见下方误区。

### ③ 精简：少即是多

- 一次会议 **3-5 人**，不要全员出场（人多了只会得到一堆泛泛而谈）
- 一个维度配 1-2 人足够，不追求"集齐所有名人"
- 董事会成员总数建议 **8-12 人**，超过 15 人会稀释每位成员的存在感

## 五、四个常见误区（请贴在墙上）

| 误区 | 真相 |
|------|------|
| **贴标签**："马斯克会这么做" | 要理解"第一性原理怎么用"，不是模仿人设 |
| **全都要**：12 人全员出场 | 每次 3-5 人，人多必泛 |
| **只换不学**：频繁换人，从没深入理解 | 先深入理解 2-3 位，再谈扩展 |
| **依赖成瘾**："董事会说可以" | 董事会给建议，决定权永远在你 |

## 六、把定制结果沉淀下来

每次组建/调整完董事会，建议做两件事：

1. **更新你的成员档案**（`member_profiles.md` 是你的本地副本，按需增删）
2. **在晨会里复盘一次**："最近 30 天，哪位成员的建议最准？哪位最没用？"——用数据调优你的董事会，而不是凭感觉。

---

> 💡 记住：**董事会是你思维的"外部化"**。它不会替你思考，但能逼你把思考变得多角度、有据、可执行。组建它的过程本身，就是一次深刻的自我认识。
