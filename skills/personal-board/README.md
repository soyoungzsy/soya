# personal-board · 个人董事会 Skill

> 遇到难题不知道怎么办？让曾国藩、芒格、马斯克等 12 位智者组成你的私人董事会，给你多角度建议。
> 这是 SOYA 自我管理体系的核心技能，配套：`soya-morning-meeting`（晨会）、`soya-card-vault`（卡片仓）。

## 🎯 功能介绍

**个人董事会**是一个决策辅助 Skill：面临重大决策时，模拟多位智者的思维方式，从多个角度分析问题，提升决策质量。

### 适用场景

- ✅ 职业选择：要不要换工作？要不要创业？
- ✅ 重大决策：买房、结婚、投资
- ✅ 个人成长：如何提升领导力？如何管理情绪？
- ✅ 情绪困扰：焦虑、迷茫、内耗时

## 💡 使用方法

直接向 AI 助手提问：

```
我是否应该离开当前岗位，加入一个 AI 创业公司？请帮我用个人董事会分析一下。
```

### 指定董事会成员

```
我想请教曾国藩、芒格和马斯克，关于是否要创业的问题。
```

### 使用模板生成器

```bash
# 生成决策分析模板
python scripts/decision_template.py "我是否应该换工作？"

# 指定问题类型
python scripts/decision_template.py "我是否应该换工作？" 职业选择

# 查看成员列表
python scripts/decision_template.py --list
```

## 📋 决策流程（5 步法）

1. **明确问题**：用 100 字以内清晰描述问题
2. **选择成员**：根据问题类型选择 3-5 位成员
3. **分别请教**：想象每位成员会如何回答
4. **汇总分析**：找出共识点、分歧点、盲点
5. **做出决策**：综合所有建议，做出最终决定

## ⚠️ 注意事项

1. **不要贴标签**：深入理解成员的思想，不要简单套用
2. **决定权在你**：董事会给建议，最终决策在你手里
3. **结合数据**：理性决策要配合事实和数据分析
4. **定期复盘**：决策后回顾，不断优化你的"董事会"
