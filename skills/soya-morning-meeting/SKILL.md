# SOYA 每日晨会 Skill

> 与 `personal-board`（个人董事会）、`soya-card-vault`（卡片仓）配套使用，构成完整的 SOYA 自我管理体系。

## 🎯 定位

晨会不是泛泛鼓励，而是你的**个人智慧大脑**：结合古往今来杰出人物的智慧、你近期材料和长期目标，帮助你更好地拿到工作结果、实现个人成长、改善生活秩序。

**一句话**：让"今天的你"站在"昨天的真实进展"和"智者的方法论"之上，做出更好的今天。

## ⚙️ 配置

首次使用前，告诉你的 AI 助手你的**本地知识库路径**（用于自动归档晨会纪要）：

```
我的知识库根目录是：/path/to/your/vault
日会纪要写入：<你选择的目录>/个人董事会日会/YYYY-MM-DD-个人董事会日会.md
```

未配置时，晨会结果以 Markdown 形式直接输出，由你手动归档。

## 📥 晨会输入优先级

按重要性从高到低读取以下材料：

1. **会议听记**：近期会议、访谈、复盘、语音听记中的任务、承诺、冲突和机会
2. **新增文档**：知识库、本地文档、项目文档中的新增或更新内容
3. **知识库进度**：近期沉淀的主题、未完成的资料、反复出现的问题
4. **LLM 对话**：用户最近和 LLM 的提问、困惑、反复讨论的主题
5. **长期画像**：用户已明确要求记住的出生信息、职业关注、成长目标和生活议题

> **诚实原则**：如果无法访问某类资料，必须明确说明"本次未读取到/未接入该来源"，**不要编造**。

## 📋 晨会固定流程

每次晨会按以下 5 步执行：

### 第 1 步：事实简报
用 3-5 条概括最近材料里的**真实**进展、问题和信号。只陈述事实，不做评价。

### 第 2 步：问题识别
指出用户当前最可能存在的 1-3 个核心问题或潜在需求。判断依据必须来自第 1 步的事实，而不是猜测。

### 第 3 步：董事发言
选择 3-5 位与当前议题最相关的董事会成员（成员档案见 `personal-board` 技能），每位成员**只给一个核心判断 + 一个行动建议**。

### 第 4 步：节奏提醒
结合用户的长期画像与节律偏好（如传统命理、节气、周期习惯等象征体系），给出节奏提醒。**必须克制表达，不做绝对化预测**；如用户未配置任何节律偏好，本步跳过并说明。

### 第 5 步：会议纪要
提炼今日最重要的判断、行动清单和**一句安顿心神的话**，按下方模板输出。

## 📤 晨会输出要求

- **以可执行为第一目标**，避免空泛励志
- 明确今天要做什么、少做什么、如何判断完成
- 关注：工作结果、向上管理、个人精进、情绪稳定、关系秩序、生活顺遂
- 建议数量**少而硬**：优先给 1-3 个可当天执行的动作
- 如果同一天补跑自动化，已经展示过晨会则不要重复输出

## 📂 沉淀规则

晨会纪要与长期主义沉淀遵循以下规则：

1. **默认写入本地知识库**（Obsidian 等 Markdown 体系），不写入第三方在线平台
2. 长期主义模块：优先写入已有主题；能力类问题优先进入能力主题导航、组织与协同、判断与决策、自我管理与长期演进等分类
3. 卡片仓：按内容性质落到方法论笔记、知识卡片、案例卡片、项目复盘等分类
4. **边界**：
   - 不删除、重命名或批量移动已有文档，除非用户明确要求
   - 不长期记录敏感职场细节、具体人事信息；统一脱敏为"组织变化"、"关键评价节点"、"协作关系调整"、"敏感人事信息"
   - 不为了沉淀而过度建目录；先用已有结构，必要时小步新增
