# Soya Personal Board · 个人董事会

**用 AI 从几个角度比较一个个人选择，帮你看清好处、风险和下一步。**

## 不会编程也可以开始

这里的 **Skill** 是“让 AI 按固定步骤做事的说明包”；**Prompt** 是“可以复制给 AI 的一段指令”。你可以先用下面的指令体验方法，不必先安装工具。

1. 打开你平时使用的 AI 聊天工具，开始一段新对话。
2. 复制下面整段文字，换掉方括号里的示例；只用你有权分享的个人材料。
3. 发送后对照“应该看到什么”检查结果。信息不够时，AI 应先提问，不应编造。

```text
帮我从三个角度比较这个个人选择：[周末是读一本书，还是完成一门入门课？]。先列已知事实和需要问我的问题，再比较好处、代价和风险，最后给出不超过三个下一步。不要假装真实人物发言。
```

**应该看到什么：** 你应看到一份比较清单、尚缺的信息和最多三个下一步。由你作决定。

AI 聊天工具可能收费，发给它的内容按该服务的规则处理；不要粘贴工作机密、私人联系方式或密码。结果不符合预期时，告诉 AI 哪一项缺少，并补充非敏感信息；你可以随时停止。

后面的安装和开发说明是进阶内容，可以先跳过。“提交问题（Issues）”指仓库顶部的提问区；只填写去除私人和工作信息的说明。

## 先试用：无需安装

```text
请用 Soya 个人董事会方法分析以下问题：[填写一个可公开的个人问题]。
先区分已知事实、我的偏好和缺失信息，再选择三种互补的思考视角。
分别提出判断与反对理由，汇总共识、分歧、盲点和最多三项下一步。
这些是 AI 对公开思想的启发式应用，不是真实人物发言；不编造引语、经历或事实。最终由我决定。
```

## 背景、用户与场景

当一个选择容易被单一立场主导时，用不同视角发现盲点。适合希望梳理个人选择、晨间重点与经验卡片的 AI 使用者；不替代专业咨询或最终决策，不保证模拟人物的观点准确。

## 完整内容与安装

- `skills/personal-board/`：多视角决策讨论。
- `skills/soya-morning-meeting/`：依据用户提供的材料形成晨会。
- `skills/soya-card-vault/`：沉淀可复用经验卡片。

下载或克隆源码后，把所需的完整 Skill 目录交给支持 Skill 的宿主，按该宿主当前官方安装机制安装，并在新会话验证可发现；先备份同名旧目录。不要运行旧版本的 `install.sh`。DSH 预设保留为兼容材料，其当前宿主行为未在本轮验证。

安装后输入：`用 $personal-board 帮我分析：[问题]`。成功结果应包含事实/未知、互补视角、分歧与下一步，而非只给一句结论。

离线模板工具（Python 3；只生成模板，不调用模型）：

```bash
python3 skills/personal-board/scripts/decision_template.py --list
python3 skills/personal-board/scripts/decision_template.py "如何安排一个阅读计划？"
```

## 隐私、费用与恢复

只使用你有权处理的材料，不输入工作机密、个人敏感信息或凭据。模型处理与留存取决于宿主，不能因本地 Markdown 就声称数据不会外传。仓库不提供模型额度；AI 宿主可能收费。

升级前备份旧 Skill 目录和个人输出，恢复时替换旧目录并重开会话；不要覆盖私人知识库。无法调用时检查宿主支持、目录层级和 SKILL.md，先使用上方无安装 Prompt。
